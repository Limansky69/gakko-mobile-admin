# Gakko Admin — прототип панели управления Gakko Mobile

PJATK Gdańsk. Самостоятельный HTML-прототип на vanilla JavaScript, без сборки и без подключения к реальному серверу для административных операций. Откройте `Gakko_Admin.html` в браузере. Google Fonts могут требовать подключения к интернету.

## Быстрый старт для агента

Прочитай AGENTS.md и указанные в нём документы. Создай отдельную рабочую копию и проверь её до изменений. Не изменяй backend. Для перехода между чатами достаточно доступа к этому репозиторию и короткой команды:

> Продолжаем работу над Gakko Admin. Прочитай AGENTS.md, восстанови контекст проекта, подготовь рабочую копию и выполни базовые проверки. Пока ничего не изменяй.

## Тесты (Linux / Bash)

Тестовые скрипты сохранены в исходном виде. Они написаны для Claude/Linux: `flowx.py` сохраняет снимки в `/home/claude/shots`, `run_all.sh` использует GNU `timeout`. В другой среде обеспечь доступ к этому каталогу и команде или отдельно адаптируй тестовые инструменты, не меняя HTML. На Windows удобно запускать через WSL. Передавай абсолютный путь HTML. Для виртуальной среды не используй `--break-system-packages`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install playwright
python -m playwright install chromium
cp Gakko_Admin.html work.html
bash tools/run_all.sh "$PWD/work.html"
GAKKO_HTML="$PWD/work.html" python3 -I tools/scan_tekst.py
```

Для одного сценария: `python3 -I tools/flowx.py "$PWD/work.html" tools/flows/nfb.json`. На Linux Chromium может потребовать системных зависимостей (`python -m playwright install-deps chromium`). Подробности и известные устаревшие шаги: [tools/README.md](tools/README.md). 11 сценариев входят в штатный прогон, два оставлены для сравнения. Проверяй лог полностью: `run_all.sh` фильтрует вывод и не гарантирует строгий ненулевой код завершения при ошибках тестов.

## Публикация и дальнейшее обновление

Рекомендуется отдельный **private** репозиторий прототипа: документы включают внутренние наблюдения о backend, а HTML — примерные данные и встроенные ресурсы. До публикации проверь разрешения на распространение данных, изображений и документации. Не добавляй токены, секреты и локальные артефакты; `.gitignore` уже исключает типовые рабочие файлы. Архив не включает backend, не содержит созданного `.git` и ничего не отправляет на GitHub.
