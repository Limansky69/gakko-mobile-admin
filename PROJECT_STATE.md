**Plan zajęć и Układanie planu**
- Легенда podglądu: «Pokaż wszystkie» справа; «Tylko z konfliktem» — треугольник. Конфликт в podglądzie отмечен на обоих занятиях: новое — пунктирная красная рамка, существующее — сплошная, оба с треугольником.
- «Sprawdź i utwórz» неактивна, пока есть хоть одна строка неполная, без дат в периоде («W okresie nie ma żadnego poniedziałku…») или повторённая («Taki sam wiersz jest wyżej. Usuń go albo zmień.»). Блока «Pominięte» больше нет. Предупреждения о выходе периода за семестр нет (владелец убрал).
- Правка одного термина серии (backend: у даты есть только дата и код Teams): если меняется дата или Teams — перенос внутри серии (`PUT /{id}/slots/{date}`), окно проверки пишет «Termin zostanie przeniesiony w ramach serii»; если время, аудитория, группы, преподаватели или предмет — выделение из серии (`DELETE` даты + `POST` одноразового занятия), пишет «Ten termin zostanie wydzielony z serii». Эти пояснения стоят сразу под статусом конфликтов, до «Zmiany». В списке «Terminy» серии выделенная дата — «osobne zajęcia» со ссылкой (панель угадывает по дате, предмету и общей группе; помечено в «Źródła danych»).
- Окно проверки: конфликты, которые были до правки, не блокируют сохранение — «Bez nowych konfliktów» и раздел «Konflikty już w planie» в конце. Галочка: «Utwórz mimo konfliktów» у новых, «Zapisz mimo konfliktów» у правки. Подзаголовок нового: «Przedmiot, 12 terminów, 10.11.2026 – 26.01.2027» или «Przedmiot, czwartek, 12.11.2026, 08:30 – 10:00».
- В карточке занятия время остаётся тремя строками (Początek, Koniec, Czas trwania), «228 (4 ITN)» — без изменений (владелец так решил).

Шапка: название и общие действия анкеты в одной верхней строке, не рядом с вкладками и не на уровне метаданных. Факты во второй строке на всю ширину (Status, Opublikowano/Otwarcie, Zamknięcie при необходимости, Odbiorcy, Autor). Подписи 12/600, значения 13/400, статус стандартным `.badge`. Отступ от заголовка до фактов 20px, подпись–значение 4px, между колонками 40px. На мобильном кнопки под фактами. Длинное редактируемое название черновика и события растёт по высоте, Enter завершает редактирование, переносы при вставке превращаются в пробелы, сохранённое значение остаётся однострочным. Устранена лишняя вертикальная прокрутка вкладок. Шапки Wydarzenia и Ogłoszenia унифицированы с анкетой, заголовки и общие бейджи исправлены глобально.

### Wyniki

Удалены четыре дублирующие KPI-плитки. Одна карточка Odpowiedzi на всю ширину: охват через `reachHTML`, например «31% odpowiedziało, 310 z 1 000», полоса на всю ширину; под сводкой тонкий разделитель с отступами по 20px, затем график. Одна шкала ответов за день, без вводящей в заблуждение кумулятивной линии со скрытой осью. Столбцы #1c1c1e, ширина до 18px, светлая сплошная сетка #ececf0; пунктир только у Publikacja/Przypomnienie с прямыми подписями; близкие метки объединяются. Tooltip по стилю Pulpit: дата, Odpowiedzi tego dnia, Łącznie do tego dnia, событие, при необходимости Dzień jeszcze trwa. Привязка к верхушке выбранного столбца, отступ 10px, справа/слева/сверху по наличию места, не выходит за пределы графика. Исправлено наложение дат. График по дням пока демо, API не отдаёт эти данные.

`Harmonogram` удалён из Wyniki и оставлен только в Odbiorcy i terminy; срок закрытия вынесен в шапку. Удалена дублирующая строка «Anonimowa, Studenci widzą wyniki» — это настройки, не результаты. Раздел называется Wyniki pytań.

Каждый вопрос — одна строка на всю ширину, слева заголовок и компактные факты, справа распределение ответов. Номер обычным текстом `1.`, без серого квадрата. Полосы соответствуют реальным процентам от 100%, не нормализованы относительно лидера; при ничьей выделяются все лидеры, при нуле никто. Количество серым, процент справа. Не возвращать дублирующие проценты лидера, медиану, шкалу средней, Oceny 4–5/1–2, Zaznaczeń na osobę и прочие показатели, которые уже видны в распределении.

**Особенно удачное решение, прямо одобренное пользователем («идеальная формула»):** слева ячейки фактов в общей рамке 1px, радиус 11px, тонкие разделители, два факта в строке; при нечётном количестве последняя ячейка занимает всю ширину. Подпись 12/600 серым, значение 13px, расстояние 2px. Typ, Odpowiedzi, при необходимости Pominęło / Bez odpowiedzi, для шкалы Średnia обычной жирности, без «z 5» (шкала уже в Typ). Для множественного выбора короткая `.ui-note` про сумму процентов. Поиск только у текстовых ответов. Не заменять ячейки длинными фразами или крупными KPI.

Свободные ответы: никакого встроенного ИИ/семантической кластеризации. Сервер объединяет только дословно совпадающие тексты, с учётом регистра. Показывать все ответы с пагинацией по 10 (общий компонент; другие модули по-прежнему по 25), сортировка Najczęstsze / A–Z по образцу Konflikty, поиск через `usNorm`, счётчик повторов «5 osób», «2 osoby», у одиночных без числа. Длинные ответы 3 строки + Pokaż całość / Zwiń только при реальном переполнении, длинные ссылки переносятся. Empty state Brak pasujących odpowiedzi отличать от Brak odpowiedzi. Демо-ответы правдоподобны, сумма соответствует числу ответивших (96 вместо 101 в соответствующем примере), старое локальное демо мигрируется один раз.

### Pytania

Опубликованная анкета — читаемое содержимое, а не форма с отключёнными контролами; черновик остаётся полноценным редактором. Заголовок вопроса выделен, тип и обязательность вторичны. Длинные названия в свёрнутых строках переносятся. Opis ankiety в белой карточке с рамкой и радиусом 12px, у черновика внутреннее поле без отдельной рамки, focus на карточке; opcjonalnie и понятный placeholder. Отступ от названия до контента у всех типов 14px. Текстовый вопрос показывает пунктирный placeholder «Pole na odpowiedź tekstową». Варианты ответа в чтении — обычный список.

Skala ocen: в чтении ряд клеток с цифрами 13/600 и крайними подписями, радиус 8px, 0–10 помещается на 390; в редакторе группы Początek skali / Koniec skali с полями 40px, на мобильном вертикально. Skip rules показывать короткой `.ui-note` со стрелкой, например «Jeśli wybrano „Nie korzystam”, przejdź do pytania 5», полный целевой вопрос в tooltip.

Сведения о серверном skip logic и его ограничениях вынесены в [BACKEND.md](BACKEND.md). В прототипе правила обновляются при переименовании и очищаются при удалении/изменении порядка/типа/границ шкалы; только переходы вперёд, без правил для текста.
