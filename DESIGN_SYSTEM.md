# Gakko Admin — дизайн-система

## Plan zajęć — эталонная страница

Plan zajęć закончен и одобрен. Это образец для всех остальных страниц: размеры, шрифты, отступы, контролы, поведение. Новое собирай из его частей, а не с нуля. Если аналог отличается по размерам или шрифтам, приводи к Plan zajęć, а не наоборот. Менять поведение самого Plan zajęć — только после согласования. Явные баги исправлять в рамках поставленной задачи; уже согласованные изменения последнего чата (overlay и зависимые фильтры) не откатывать.

Основные части (префикс `tt`):
- **Линзы** `o / g / l / s` (Plan ogólny, Plan grupy, Plan prowadzącego, Plan studenta), вкладки `TT_TABS`.
- **Сетка** `ttGridHTML(days, items, G, opt)` с опциями `nodate / i0 / full / dayBtn`, раскладка `ttCompute`, вид по аудиториям (`.tt-rooms`).
- **Конфликты**: `ttConflicts`, `ttConfWeek`, панель `ttOpenConf`. Строка конфликта — `ttCfRowHTML` / `ttCfItemHTML`: вся строка открывает подробности (`.tt-cfx`), из кнопок только «Edytuj».
- **Формы**: `ttFormHTML` / `ttFieldsHTML`, операции `ttOpNew`, `ttOpEdit`, `ttOpDel`, выполнение `ttRun`. Повтор только еженедельный (`ttSeries`, шаг 7), «co 2 tygodnie» нет и не будет. Варианты повтора: «Jednorazowo» / «Co tydzień».
- **Правка серии**: переключатель «Tylko ten termin / Ten i następne / Wszystkie», по умолчанию «Tylko ten termin». Подпись ниже: «Edycja jednego terminu: …» или «Edycja N terminów: …».
- **Układanie planu** (build mode): `ttD()`, `tt.b`, атомарный `POST /group-classes/schedule` через `ttBuildSteps`. Окно «Sprawdź nowe zajęcia» — боковая панель (как в «Nowe zajęcia»), рисуется в `#modalRoot` (`.tt-bsheet`).
- **Боковые панели** `.ui-sheet` (`.ui-sh-h / -n / -b / -f`), затемнение `.ui-shade`.
- **Поповеры и календари**: `.tt-pop`. В календаре всегда 42 дня.
- **Подписи групп**: `grpList`, `ttGSum` («GIs I.1 - 11c i 2 inne»).
- **Даты**: `ttNum`, `ttDayW`, `ttFromTo(a, b)` даёт «08:30 – 10:00».

Общие механизмы: `state`, `render()`, `navigate(page)`, `persist()`, `ttRerender()`; `modal()`, `toast()`, `icon(name, cls)`, `esc()`, `$`; `nothing()` и `emptyStart()`; `csEnhance` / `.cs-btn`; `dtEnhance` / `dtScan()`.

Модули по префиксам: `wm` Wiadomości, `ev` Wydarzenia, `an` Ogłoszenia, `sv` Ankiety, `od` Odbiorcy, `us` Użytkownicy, `tm` Zespół i role, `dash` Pulpit.

Права: `IS_ADMIN`, `canPage`, `ADMIN_PAGES`, `denyAct`. Режим данных: `EMPTY` («Brak danych» / «Przykładowe»), `dataSwitch`.

## Дизайн-система

Правила записаны в комментариях CSS внутри файла. Прочитай их перед любой визуальной правкой и соблюдай буквально:
- SKALA TYPOGRAFII I KONTROLEK;
- REJESTR;
- DATA I GODZINA;
- SEPARATORY (в том числе маркер списка в тексте объявления — «– »);
- PASEK FILTRÓW (отступы как в Plan zajęć, подсказка поиска «Szukaj w …», пустой контрол — тонкая подсказка);
- LICZBY PRZY ETYKIETACH;
- ZASIĘG (единый показатель «31% odpowiedziało, 310 z 1 000» — `reachHTML`);
- LISTA WYBORU (единый выбор из списка — `ttPickHTML`, правило «×»);
- PUSTY STAN;
- ZAZNACZONA KARTA;
- POLA ZAJĘĆ;
- POLA FORMULARZA;
- PASEK PRZEWIJANIA W ZAOKRĄGLONYCH POJEMNIKACH;
- STRZAŁKA LISTY ROZWIJANEJ;
- MENU BOCZNE.

Если вводишь новое правило, допиши его в соответствующий комментарий.

Основное:
- **Шрифты**: DM Sans для текста и контролов, Manrope для заголовков, крупных чисел и надписи «Gakko Mobile». Третьего шрифта нет.
- **Шкала**: `--t-xs` 11 / `--t-sm` 12 / `--t-md` 13 / `--t-lg` 15 / `--t-xl` 20 / `--t-2xl` 28. Начертания 400 / 600 / 700. Высота контрола фильтров 36px, 13px / 600; поля форм 40px, значения 400. Размеры в px «на глаз» не задаются.
- **Текст**: вспомогательный цвет `--ink-2` #66666f, подсказки `--ui-ph` #737380. Текст не меньше 11px, обычный не меньше 12px, контраст не ниже 4,5:1.
- **Регистр**: везде «как в предложении». Капслок и декоративный `letter-spacing` не используются; для крупных заголовков Manrope 28px согласовано −0.5px.
- **Дата и время**: dd.MM.yyyy, только 24 часа, **никогда AM/PM**.
- **Диапазоны**: «12:00 – 16:00», «02.11.2026 – 08.11.2026» (короткое тире с пробелами). Без пробелов только числовые: «1–20 z 107», «1–5».
- **Счётчики**: «ile tego jest» — серая цифра без фона и рамки, ноль не показывается. Для непрочитанного — нейтральная плашка; семантические статусы — единый `.badge` с точкой, 12px/600. Красный не использовать декоративно; фирменный акцент для действий и активного состояния сохраняется.
- **Пустые состояния** только через `nothing()` / `emptyStart()`.
- **Скругления**: содержимое не выходит за угол, внутри `.panel` — `overflow: clip`.
- **Имена**: «Imię Nazwisko» везде, кроме списков выбора и их кнопок, где фамилия первой (`ttLectSF`) — для поиска по алфавиту.

## Анти-слоп (правила владельца)

- **Нигде нет разделителя «·»** и маркера «•». Части текста соединяются запятой, двоеточием или переносом строки.
- Пилюли, теги и квадратные бейджи-счётчики не используются.
- Анимации — только если попросили.
- Тексты интерфейса не пишутся от первого лица множественного числа.
- Нет «надзаголовков» капслоком, градиентов, декоративных иконок над каждым заголовком.
- Подписи короткие и конкретные. Если подпись ничего не добавляет, её не должно быть.
- Каждый новый текст проверяй на шаблонность и на польскую грамматику (числа: 1 termin / 2–4 terminy / 5+ terminów; «Pozostałe 3 … się nie zmienią», но «Pozostałych 16 … się nie zmieni»).

## Уточнения дизайн-системы

Не превращай каждую цифру в KPI. Не заполняй свободное место ради заполнения. Не копируй Plan zajęć механически: сопоставляй семантику и вычисленные стили, сохраняй единую иерархию.

- Manrope для заголовков; заголовки страниц 28px с letter-spacing −0.5px (было −1.35px); 15px/700 для заголовков карточек. DM Sans для обычного интерфейса. Названия пунктов внутри карточек обычно 13px/700 (например, шаг Harmonogram, Wszyscy studenci), названия вопросов в списке 13px/600.
- Обычные значения 13px/400; вспомогательный текст 12px серым. Факты с подписью сверху: 12px/600 серым и значение 13px/400 тёмным. Подписи полей 12px/600 #3b3e48. Основной текст #1c1c1e. Числа без необоснованной жирности.
- Единый `.badge`: цвет статуса, точка, 12px/600; не переопределять отдельно в шапке. `Bez konfliktów` тоже 12px. Красный не использовать как украшение графика/метрики, оставить семантически оправданным.
- `.tabs / .tab` вместо `.sv-tabs`: 13px/600, 48px. `.btn.small` для малых действий, `.ui-note` для коротких пояснений, `.ui-ferr` для ошибок, `.ui-facts` для пар подпись–значение. Поля формы стандартно 40px, текст 13px/400. Быстрый выбор срока `.quick` с радиусом 7px, без пилюль.
- Выбранная карточка обозначается рамкой, без дополнительной зелёной точки. Общая пагинация и общий поиск, включая `usNorm` (без чувствительности к диакритике), вместо дублирования реализации.

## Согласованные правила выбора из списка

- Группы, преподаватели, аудитории, студент — везде кнопка со списком и поиском «Szukaj …». Поле с вводом (`ttCbHTML`) только у предмета: там можно создать новый. День недели и повтор — обычный select.
- Аудитории в списке сгруппированы по корпусам; в формах справа занятость: «wolna» серым или «zajęta w 12 terminach» цветом предупреждения. Под полем: «A310: zajęta w 3 terminach. Pokaż plan»; в Układaniu planu ещё «… w tym czasie także w wierszu 2. Pokaż wiersz» (занятость из соседней строки черновика — отдельно от плана).
- Несколько значений (группы, преподаватели в формах): галочки и нижняя строка «N wybranych, Wyczyść, Gotowe». Одно значение: список закрывается сразу, нижней строки нет.
- «×» в поле — только там, где пустое поле — нормальное состояние: поиск, «Wybierz salę» в Plan ogólny, группы в Plan grupy. Также Delete / Backspace. В обязательных полях форм (предмет, группы, преподаватель, аудитория) «×» нет.
- На панели фильтров пустая кнопка выбора — тонкая подсказка (400, `--ui-ph`), выбранное значение — 600 тёмным. Аудитория в Plan ogólny называется «Wybierz salę» (выбор только подсвечивает колонку, не фильтрует).
- Список выбора открывается вверх, если снизу нет места (`ttGdPlace`).
